Parámetros de tienda

Turnos

Turnos predeterminados: amanecida 00–08, apertura 08–16 y cierre 16–00. Puedes cambiar sus horas. Desactiva amanecida para tiendas de dos turnos.

Cobertura mínima por día y turno

Define personal de producción y servicio. Además se exige al menos un gerente o asistente en cada turno activo.

Propuestas de horarios

Genera varias alternativas. Las restricciones obligatorias se verifican antes de aprobar; las preferencias afectan el puntaje.

Propuestas guardadas

Para editar manualmente, selecciona una celda del horario. Las modificaciones se validan antes de guardar.

Confirmación de restricciones

Genera enlaces de lectura y confirmación para cada trabajador. Los pendientes no impiden generar horarios.
